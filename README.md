# Emma 空域 KML 製作工具

## 上傳 GitHub Pages
1. 解壓縮 ZIP。
2. 將 index.html、app.js、.nojekyll 上傳到新儲存庫的最外層（不要上傳 ZIP 本身）。
3. 儲存庫 Settings → Pages → Deploy from a branch → main / (root) → Save。
4. 等待 GitHub Pages 顯示網址後開啟。

若要放在既有網站的子資料夾，也可將這些檔案一起放在例如 airspace/，從原網站網址加上 /airspace/ 開啟。

## 使用
- 預設為 QT 三點範例，可直接修改。
- 多邊形：每行一個頂點，格式 N2250.00 E12032.00，依邊界順序排列，至少三個不同頂點。自動連回起點。
- 圓形：選擇圓形，輸入圓心（同樣格式）與半徑，單位為海浬 NM。
- 每個空域可設定名稱、線條顏色與半透明填色。
- 按「新增空域」繼續加入圖形，按「下載 KML」合併匯出一個檔案。
- iPhone/iPad 下載後可從「檔案」App 分享到支援的軟體。

## 注意
- 使用 WGS84 座標。圓形以 WGS84 橢球測地線計算180個頂點近似，邊線仍為短線段。
- 目前為貼地的二維圖形，不包含上下限高度。
- 預覽為形狀示意，無底圖；跨越180度經線的圖形預覽可能不正確。
- 資料只自動保存在目前瀏覽器；換裝置、清除瀏覽資料不會保留，請下載檔案留存。
- 不需要安裝套件或編譯，沒有外部程式依賴。
- 已驗證座標轉換、圓形產生、多空域KML、XML與封閉邊界；尚未實測手機下載及ForeFlight匯入。
